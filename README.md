# Auxilium — demo de portfólio

Experiência estática, navegável e responsiva de doações fictícias. Não realiza doações reais.

## Abrir

Abra `index.html` no navegador ou sirva esta pasta com qualquer servidor estático. Não exige instalação, dependências ou compilação.

## Experimentar

- Busque por livros, roupas ou alimentos; combine categoria e cidade e ordene os resultados.
- Explore detalhes, favoritos e Minha atividade.
- Cadastre um item fictício, revise, edite e conclua.
- Use Reiniciar demonstração para repetir a apresentação.

## Dados e limites

Itens, organizações, quantidades e interações são fictícios. Não insira dados pessoais reais. O estado existe somente na memória da aba: recarregar reinicia tudo. Não há autenticação, geolocalização, armazenamento persistente, API, pagamento, e-mail ou contato externo. Fontes do sistema e ilustrações locais, sem dependências de rede. A CSP bloqueia conexões externas.

## Arquitetura

HTML, CSS e JavaScript, com roteamento por hash e caminhos relativos compatíveis com GitHub Pages. Textos digitados são escapados antes de renderizar; modais usam `<dialog>` nativo.

## Identidade

Auxilium usa laranja quente, neutros claros, verde de apoio e o símbolo de coração sobre caixa de doações. Logo original de Vinicius Oliveira.
